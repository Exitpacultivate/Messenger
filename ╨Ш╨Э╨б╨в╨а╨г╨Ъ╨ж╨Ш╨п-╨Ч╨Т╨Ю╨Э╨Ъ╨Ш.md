# Как включить звонки между разными сетями (TURN-сервер)

Звонки соединяются напрямую (P2P). Когда собеседники в разных сетях (Wi-Fi ↔ мобильный
интернет), прямое соединение часто блокируется — нужен TURN-сервер-ретранслятор.
Раньше существовал публичный Open Relay, но проект закрыт. Бесплатный TURN теперь
выдаётся после регистрации (5 минут, карта не нужна, 50 ГБ трафика в месяц бесплатно):

1. Зайдите на **https://dashboard.metered.ca/signup** и создайте аккаунт
2. Создайте приложение (App) — название любое
3. Слева откройте раздел **TURN Servers** → там будут Credentials:
   - список URL вида `turn:a.relay.metered.ca:80`, `turn:a.relay.metered.ca:443` и т.п.
   - **Username** и **Credential** (пароль)
4. Откройте **Vercel → ваш проект → Settings → Environment Variables** и добавьте три переменные:
   - `VITE_TURN_URL` — все URL через запятую, например:
     `turn:a.relay.metered.ca:80,turn:a.relay.metered.ca:443,turns:a.relay.metered.ca:443?transport=tcp`
   - `VITE_TURN_USERNAME` — username из кабинета
   - `VITE_TURN_CREDENTIAL` — credential из кабинета
5. Vercel → Deployments → у верхнего деплоя меню ⋯ → **Redeploy** (переменные применяются только при пересборке)

Проверка: позвоните друг другу с разных сетей (один на Wi-Fi, второй на мобильном).
Если на экране звонка висит «Соединяем…» дольше 10 секунд — TURN не настроен или
переменные введены с опечаткой.

Без этих переменных звонки работают только внутри «простых» сетей (например, оба в одном Wi-Fi).
