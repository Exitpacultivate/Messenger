# Запуск мессенджера: Supabase + Vercel

Всё бесплатно, занимает ~20 минут. Понадобятся три аккаунта: GitHub, Supabase, Vercel.
Регистрируйтесь сами и нигде не сообщайте пароли — даже ИИ-ассистентам.

---

## Шаг 1. База данных — Supabase (~7 минут)

1. Откройте **supabase.com** → Start your project → зарегистрируйтесь (проще всего через GitHub, тогда начните с шага 2 GitHub ниже)
2. Нажмите **New project**:
   - Name: `messenger`
   - Database Password: придумайте и **сохраните где-нибудь** (понадобится редко, но потерять нельзя)
   - Region: `Central EU (Frankfurt)` — ближайший к вам
3. Подождите 1–2 минуты, пока проект создаётся
4. Слева в меню откройте **SQL Editor** → New query → вставьте туда **всё содержимое файла `supabase-schema.sql`** из этой папки → нажмите **Run**. Внизу должно появиться "Success. No rows returned"
5. Слева: **Authentication → Sign In / Providers → Email** → выключите переключатель **Confirm email** → Save. (Наши логины — не настоящие почты, подтверждать нечего)
6. Слева: **Project Settings → Data API** (или просто API):
   - скопируйте **Project URL** (вида `https://xxxx.supabase.co`)
   - скопируйте ключ **anon public** (длинная строка)
   - сохраните оба в блокнот — нужны на шаге 3

> Ключ anon public не секретный — он создан для использования в браузере, доступ к данным ограничивает сама база (политики RLS из схемы).

## Шаг 2. Код — GitHub (~5 минут)

1. Откройте **github.com** → Sign up → зарегистрируйтесь
2. Нажмите **+** (вверху справа) → **New repository**:
   - Repository name: `messenger`
   - Public
   - → Create repository
3. На странице нового репозитория нажмите ссылку **uploading an existing file**
4. Перетащите в окно **всё содержимое папки проекта** (файлы и папку `src`):
   - `package.json`, `vite.config.js`, `index.html`, `.gitignore`, `supabase-schema.sql`, `ИНСТРУКЦИЯ.md`, папку `src` целиком
   - НЕ загружайте папки `node_modules` и `dist`, если они есть — они не нужны
5. Внизу нажмите **Commit changes**

## Шаг 3. Хостинг — Vercel (~5 минут)

1. Откройте **vercel.com** → Sign Up → выберите **Continue with GitHub** и разрешите доступ
2. Нажмите **Add New… → Project** → напротив репозитория `messenger` нажмите **Import**
3. Vercel сам определит, что это Vite. Перед деплоем раскройте секцию **Environment Variables** и добавьте две переменные:
   - Name: `VITE_SUPABASE_URL` → Value: ваш Project URL из шага 1.6
   - Name: `VITE_SUPABASE_ANON_KEY` → Value: ваш anon public ключ из шага 1.6
4. Нажмите **Deploy** и подождите ~1 минуту
5. Готово! Vercel покажет адрес вида `https://messenger-xxxx.vercel.app` — это и есть ваш мессенджер. Отправляйте ссылку друзьям

## Как обновлять приложение

Когда я пришлю новую версию файлов: откройте репозиторий на GitHub → **Add file → Upload files** → перетащите изменённые файлы (они заменят старые) → Commit. Vercel пересоберёт сайт автоматически за минуту.

## Если что-то пошло не так

- **Сайт открылся с надписью «Почти готово»** — не добавлены переменные на шаге 3.3. Vercel → ваш проект → Settings → Environment Variables → добавьте → вкладка Deployments → у последнего нажмите ⋯ → Redeploy
- **«Не удалось создать аккаунт» при регистрации** — скорее всего, не выключен Confirm email (шаг 1.5)
- **Ошибки про таблицы** — схема не применилась, повторите шаг 1.4
- Любая другая проблема — пришлите мне текст ошибки или скриншот

## Лимиты бесплатных тарифов

Supabase: 500 МБ база, realtime до 200 одновременных подключений — на компанию друзей хватит с запасом. Vercel: 100 ГБ трафика в месяц. Если проект «выстрелит», оба сервиса масштабируются платно без переезда.
