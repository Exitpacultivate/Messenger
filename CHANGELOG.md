# История обновлений мессенджера

## v0.1 — «Беседка» (прототип в Claude)
Первая проба: общая лента сообщений с именами и лайками внутри артефакта Claude.

## v1.0 — Мессенджер (артефакт)
Telegram-стиль: регистрация с @тегом, личные чаты, поиск по тегу, текст/фото/файлы/голосовые,
ответы, реакции, закрепы, черновики, поиск по чату, эмодзи-пикер, быстрые ответы,
3 темы + 8 акцентов, статусы онлайн и «печатает», мобильная адаптация.

## v1.1–1.2 — Стабилизация артефакта
Починка аватаров и экспорта (особенности песочницы), мгновенная отправка, обои чата (10 + свои),
звук печати, баннеры профиля и рамки аватара, профиль собеседника, объединённое меню скрепки,
защита базы от затирания при сбоях хранилища, диагностика соединения.

## v2.0 — Переезд на Supabase + Vercel 🚀
Собственный сайт. Настоящая авторизация, мгновенная доставка (realtime вместо опроса),
защита данных политиками на уровне БД, presence-статусы, рабочие голосовые, экспорт файлом.

## v2.1 — Группы и медиа
Групповые чаты: создание, участники, имена отправителей. Реакции мгновенные, двойной тап = ❤️,
долгое нажатие на телефонах. Все медиа в Supabase Storage: видео доставляются мгновенно, лимит 25 МБ.

## v2.2 — Волна P1 + группы 2.0
Выход из чата свайпом и Esc. Голосовые в качестве 128 кбит/с (Opus, шумоподавление).
Реакция любым эмодзи, наборы ×2. Отправка оригиналов без сжатия. Свой цвет акцента, рамки
и баннера с палитры. Профиль группы: аватар, название, описание, баннер. Админы с настраиваемыми
правами (исключение, назначение админов, редактирование). iOS-панель группы с медиатекой
по категориям (фото, видео, файлы, аудио, ссылки, голосовые, GIF). Режим «без звука». Фавиконка.

## v2.3 — Волна P2 (текущая)
Папки чатов (свои + автопапка «Друзья»). Избранное — личный чат-заметки. Друзья/контакты.
Блокировки: заблокированный не может писать (защита в БД). Кадрирование аватара с зумом
и выбором положения. Смена имени, @тега и пароля в настройках. Клик по закрепу проматывает
к сообщению с подсветкой. «Кто прочитал» для своих сообщений в группах. Онлайн-статусы
в списке участников, клик по участнику открывает профиль с кнопками «Написать» и «В друзья».

## v2.4 — Каналы и администрация
Каналы как в Telegram: публикуют владелец и админы, остальные подписываются и читают;
поиск каналов по названию, подписка в один клик. Роль «админ мессенджера» (защищена на уровне БД).
Глобальные объявления: плашка над списком чатов у всех пользователей, клик открывает главный
канал мессенджера. Назначение главного канала — кнопка в шапке канала, видна только админу.
